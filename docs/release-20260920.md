# Lotline production release — September 20, 2026

This is an authorized release of the existing application, following the [September 19 local checkpoint](finish-report-20260919.md). Local dates use Asia/Ho_Chi_Minh; evidence timestamps use UTC.

## Included changes

Exact receipt/recovery checks, immutable atomic execution journaling, unsigned-expiry recovery, duplicate-approval protection, downloadable receipts, stable manual reminder snapshots/cloud sync, and the explicitly labeled silent controlled walkthrough on `/demo`. The selected design, logo, 832-identity Example, ten-asset calculations, brand kit and both narrated planner films are preserved.
