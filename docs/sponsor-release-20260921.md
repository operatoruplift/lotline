# Lotline sponsor continuation — September 21, 2026

This release extends the existing contribution product with a separate PreStocks planner and an optional Pyth reference panel. It preserves the implemented design, logo, original films, authentication, xStocks catalog, exact contribution math, and disabled-by-default purchase gates. No trade, token launch, pool creation, competition submission, or domain purchase was performed.

## Delivered behavior

- `/pre-ipo`: eight pinned PreStocks assets, official bundled logos, issuer identity checks, Solana mainnet verification, exact USDC allocation, read-only Jupiter estimates and scaled-unit conversion. Its draft key and v2 share links identify the PreStocks universe. Cross-universe imports cannot replace another draft; existing xStocks v1 links remain supported.
- PreStocks has local drafts and copy/CSV/share, with explicit planning-only copy. It does not expose cloud plans, manual reminders, Tokens.xyz context, Pyth, or in-app execution. Its issuer API publishes no halt flag, so the receipt says it is not published; on-chain pause verification is a separate quote precondition.
- `/app`: the original xStocks flow now requests independent Pyth equity/token references after successful Live estimates for pinned AAPLx, MSFTx and NVDAx. Prices and confidence preserve integer/exponent precision. Freshness expires 60 seconds from publication; it is never renewed by retrieval or rendering. Original Jupiter quotes keep their separate maximum 30-second lifetime. Edits invalidate both views, and obsolete requests cannot overwrite a changed plan.
- Pyth token-feed unit basis remains unverified relative to Solana scaled quantities. There is no premium/discount, fair-value, or oracle-equivalent execution-price calculation. The panel does not authorize purchases or substitute for Jupiter output.

## Real provider observations

The [PreStocks contract and evidence](releases/2026-09-21/prestocks-integration.md) records all eight issuer identities and actual mainnet configuration. OPENAI and SPACEX showed non-unit scaling. A real OPENAI 10-USDC quote returned a null transaction and converted successfully using the official Token-2022 helper. An opt-in adapter test separately passed catalog, quote and projection reads. A second real adapter run then returned successful 10-USDC quotes and scaled-unit conversions for all eight identities (8/8); the [per-asset evidence](releases/2026-09-21/prestocks-all-quotes.json) records raw output, chain context, and null transaction responses. No wallet signature or transaction submission occurred.

PreStocks transfer-fee/confidential account extensions are unsupported by the current holdings decoder and purchase validator. Such holdings remain unavailable, never a fabricated zero. The adapter can convert validated raw amounts without claiming unsupported account decoding or transfer semantics.

The [Pyth discovery and contract](releases/2026-09-21/pyth-integration.md) records six official feed IDs. Catalog discovery returned HTTP 200; both official current-price endpoints returned HTTP 401 without a key. The official Core documentation now requires API access. `PYTH_API_KEY` is documented as server-only. Deterministic price fixtures validate behavior but do not establish live price delivery. Authenticated Pyth price access remains unverified until the key is configured and a real read passes.
